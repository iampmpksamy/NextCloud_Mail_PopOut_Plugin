# Mail Pop-out

Mail Pop-out makes the Nextcloud Mail composer draggable and resizable and lets you detach the live composer into a separate browser window.

![Annotated Mail Pop-out composer](https://raw.githubusercontent.com/iampmpksamy/NextCloud_Mail_PopOut_Plugin/main/docs/images/mail-popout-composer-mockup.png)

The highlighted control opens the existing composer in a new browser window. Recipients, message content, attachments, drafts, and Mail's Send action remain managed by Nextcloud Mail.

## Start here

1. Follow the [Installation](Installation) guide.
2. Hard-refresh Mail after enabling the app.
3. Read [Using the Composer](Using-the-Composer) to detach and return the composer.
4. If the icon is missing, open [Troubleshooting](Troubleshooting).

## Main features

- Draggable, resizable in-page composer
- Separate browser-window mode
- Mail draft and send behavior preserved
- Nextcloud menus and CKEditor balloons moved with the detached composer
- Mail 5.10 modal and newer floating composer compatibility
- Local position and size memory
