# Using the Composer

![Pop-out control location](https://raw.githubusercontent.com/iampmpksamy/NextCloud_Mail_PopOut_Plugin/main/docs/images/mail-popout-composer-mockup.png)

## Open a floating composer

Start a new message, reply, forward, or open a draft normally. The composer appears without the page-blocking dark backdrop.

- Drag the composer using its title bar.
- Resize it from the lower-right resize handle.
- The last in-page position and size are stored in the browser.

## Open a separate window

Select the highlighted square-and-arrow icon in the upper-right composer title bar. It appears before Mail's minimize, maximize, and close controls.

The live composer moves into a separate browser window. It is not copied, so the message content and draft state remain the same.

## Return to Mail

Use any of these methods:

- Select the square-and-arrow icon again in the detached window.
- Select **Return** in the small indicator shown on the Mail page.
- Close the detached browser window.

## Minimize and close

Mail's native minimize and close controls keep their original behavior. Mail remains responsible for draft saving, discard confirmation, attachments, and sending.

The installed Mail version controls how many simultaneous composer sessions are available.
